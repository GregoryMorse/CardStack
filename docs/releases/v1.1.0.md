# CardStack 1.1.0

This release strengthens deck security, saving, template editing and report printing, with expanded automated and visual regression coverage.

## Important before upgrading

**Back up your decks before opening and saving them with 1.1.**

CardStack 1.1 uses SQLite schema version 3 and introduces a versioned encrypted file format. Use CardStack 1.1 or newer for upgraded files: older versions cannot read encrypted 1.1 files and may discard newer report/font metadata from unencrypted files.

Password-only protection is an application access check, not encryption. Enable **data encryption** to protect saved contents. Keep your password safe; there is no password recovery. Template/report sharing files and other unencrypted exports are not protected by the deck's encryption.

The cryptographic integration uses pinned Monocypher primitives and has automated known-answer, wrong-password and tamper tests. It has not undergone an independent security audit. See [deck security](https://github.com/GregoryMorse/CardStack/blob/v1.1.0/docs/security.md) for details and limitations.

## Security and reliable saving

- Real authenticated XChaCha20-Poly1305 encryption, with salted Argon2id password verification.
- Case-sensitive passwords with spaces and Unicode, up to 1,024 characters.
- Decrypted working databases stay in memory; encrypted saves do not create a plaintext temporary database.
- Atomic file replacement, duplicate-open protection, document locks and stale-save detection.
- Read-only source probing and rejection of unsupported storage versions without modifying the source.
- Existing protected files migrate on save while retaining their previous password comparison rules.

## Decks, templates and windows

- Preserve call history, appearance, metadata and document identity when cards or schemas change.
- Fix incomplete call-log entries failing to save.
- New template data boxes get independent fields; draft templates can save/export without an owner deck.
- Preserve template appearance during sharing and patterned creation.
- Keep report field bindings intact when fields are renamed.
- Safer dependent-window closing, with save/cancel handling before the owner deck closes.
- Prevent card-navigation shortcuts from acting behind modal dialogs.
- Correct normal-weight built-in fonts and caption sizing without moving template field geometry.

## Reports and printing

- Correct font descriptors, geometry, margins, band classification and metadata for all 45 built-in report presets.
- Honor physical paper dimensions and orientation for printing.
- Print every selected search match instead of falling back to the current card.
- Shared text metrics for preview, printing and multi-field continuation.
- Distinct line/fill patterns, including density and hatch variants.
- Resolve abbreviated imported field names; missing optional fields no longer print literal bracket syntax.
- Correct header/footer units and custom-form defaults.
- Resizable print preview makes better use of the available viewport and preserves paper aspect ratio.

## Validation

- Local Windows Release validation: 18/18 CTest suites passed.
- Native Print-to-PDF integration passed.
- 193 fresh production-styled captures reviewed across dialogs, card/table views, toolbars, both designers and reports.
- Cross-platform CI and packaging are required before this release is published.

Font availability, native platform styles and printer drivers can affect rendering. This release does not claim pixel-identical output for every original printer configuration. Retain original migration files and backups.
